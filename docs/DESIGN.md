# 设计取舍

这份文档记录「为什么这么做」，以及被否掉的备选方案。代码能看出做了什么，看不出为什么没选另一条路。

## 1. 为什么不直接用 RuoYi-Vue-Plus 改

RuoYi 是成熟的后台脚手架，直接用能省掉权限模块的活。但：

- 它的代码量和依赖太多，一个课程选课系统用不到工作流、代码生成器、多数据源；
- 面试时讲「我改了别人的脚手架」，说服力远低于「我自己设计了权限模型」；
- 自研后每个决策都能解释：为什么权限点放令牌里、为什么菜单下发在后端。

所以做法是：**借鉴 RuoYi 的 RBAC 模型（用户-角色-菜单三段式，按钮也作为菜单行存 perm），代码全部自研**。

## 2. 选课为什么用数据库行锁，而不是 Redis 预扣

`UPDATE edu_offering SET enrolled = enrolled + 1 WHERE id = ? AND enrolled < capacity` 依赖 InnoDB 行锁，
在单机几十到几百 QPS 的量级完全够用，且不需要引入 Redis、不用处理「Redis 扣了但数据库写失败」的对账问题。

什么时候该换：热门课开抢、瞬时上千并发时，同一行的锁等待会成为瓶颈。
那时的手段是 Redis `DECR` 预扣名额 + MQ 异步落库 + 定时对账，代价是多一套一致性问题。
**本项目刻意选了简单方案，并把换方案的条件写在 README 里**，而不是假装它能扛双十一。

被否掉的另一个方案：`SELECT ... FOR UPDATE` 先锁行再判断。能work，但多一次往返，
而且把锁持有时间拉长到整个事务，比条件 UPDATE 差。

## 3. 时间冲突为什么不在数据库层用约束表达

「同一天节次区间不能重叠」是区间相交问题，MySQL 没有区间排他约束（PostgreSQL 的 `EXCLUDE USING gist` 可以）。
可选方案：

- 在应用层算（本项目）：一次查询拿到学生所有时段，Java 里比较，规则可读、报错信息能带出撞了哪门课；
- 存一张「学生-节次」占用表，每节课一行，靠唯一索引挡：能挡，但一个学生选 8 门课要写几十行，
  退课/改时间还要同步维护，复杂度不成比例。

## 4. 权限点放 JWT 里，而不是每次查库

- 放令牌：每个请求零查询，代价是权限变更要等令牌过期（8 小时）或重新登录；
- 每次查库：即时生效，但每个请求多 2 次 JOIN 查询，还得配缓存，否则数据库压力翻倍；
- 放 Redis：两者兼得，但本项目刻意不引入中间件。

选第一种，并在 README 的局限里明确写出「改角色后需重新登录」。
如果真上线，正确做法是 Redis 存 `userId -> perms`，授权变更时 `DEL` 对应 key。

## 5. 统一返回体 + HTTP 状态码，而不是「永远 200」

不少后台项目所有响应都是 HTTP 200，用 body 里的 `code` 表达错误。本项目选择**让 HTTP 状态码说真话**：

- 401 未登录、403 无权限、404 不存在、409 冲突、400 参数/业务错误；
- 前端 axios 拦截器按状态分流：401 清令牌跳登录、403 提示无权限、其余弹后端 msg。

好处是网关、监控、浏览器 devtools 都能直接看出请求成败，不用解包 body。
代价是前端拦截器要多写几行——这个成本值得。

## 6. 成绩计算放在后端

总评与绩点如果交给前端算，等于把「学生能不能改自己的分」交给了浏览器。
放在 `ScoreService` 里还有一个好处：换算表只有一处，改权重不用前后端一起改。

## 7. 测试用 H2 而不是本地 MySQL

- 同一份 `schema.sql` / `data.sql` 在 H2 的 MySQL 模式下也能跑，测试不需要装数据库、不需要清库；
- CI 里 `mvn test` 直接绿，不用起 MySQL 容器；
- 风险是 H2 与 MySQL 有方言差异（本项目只用了两边都支持的基础语法：`LIMIT`、`CONCAT`、条件更新），

所以**真实库仍然要跑一遍**——本地配置 MySQL 后手工验证了建库、登录、选课、录分全流程。

## 8. 前端为什么用 Hash 路由

`createWebHashHistory` 的 URL 带 `#`，不如 History 模式好看。但：

- 打包后放进 Spring Boot 的 `static/` 直接可用，不需要给 Nginx 配 `try_files`；
- 刷新页面不会 404（History 模式在没配 fallback 时刷新就白屏）；
- 演示项目优先「clone 下来能跑」，不优先 URL 美观。

如果部署到独立 Nginx，改一行 `createWebHistory()` 加上 `try_files $uri $uri/ /index.html` 即可。
